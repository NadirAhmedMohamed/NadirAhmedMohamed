## 🚀 Featured Projects

### 🛒 Nad Store — E-commerce Platform

A full-featured e-commerce application built with React and Firebase, designed to provide a complete online shopping experience.

**Key Features:**

- User authentication and Google Sign-In.
- Product catalog, categories, search, and shopping cart.
- Checkout and Stripe payment integration.
- Payment webhook verification using Cloudflare Workers.
- Order management and order tracking.
- Admin dashboard and protected routes.
- Responsive design with Arabic RTL and English LTR support.

**Tech:** React.js, Firebase Authentication, Firestore, Stripe, Cloudflare Workers.

🔗 [Live Demo](https://nad-store.pages.dev) | [GitHub Repository](https://github.com/NadirAhmedMohamed/nad-store)
